# STM32F407 园区巡航小车引脚说明

本文档只记录当前仓库保留的运动控制核心模块。

## 主控

| 项目 | 配置 |
|---|---|
| MCU | STM32F407 |
| 内核 | ARM Cortex-M4 |
| 系统时钟 | 168 MHz |
| 开发库 | STM32F4 Standard Peripheral Library |

## 电机驱动与 PWM

| 引脚 | 功能 |
|---|---|
| PE8 | 左电机方向控制 1 |
| PE10 | 左电机方向控制 2 |
| PB1 | 右电机方向控制 1 |
| PC5 | 右电机方向控制 2 |
| PE5 | 左电机 PWM 输出 |
| PE6 | 右电机 PWM 输出 |

## 编码器

左轮编码器使用 TIM8 编码器接口，右轮编码器使用 TIM5 编码器接口。

| 定时器 | 引脚 | 功能 |
|---|---|---|
| TIM8 | PC6 | 左轮编码器 A 相 |
| TIM8 | PC7 | 左轮编码器 B 相 |
| TIM5 | PA0 | 右轮编码器 A 相 |
| TIM5 | PA1 | 右轮编码器 B 相 |

## MPU6050

当前工程使用软件 I2C 读取 MPU6050 数据。

| 引脚 | 功能 |
|---|---|
| PB10 | SCL |
| PB11 | SDA |

## OLED

OLED 使用独立软件 I2C 接口，用于显示目标速度、目标角度和左右轮速度。

| 引脚 | 功能 |
|---|---|
| PB7 | SDA |
| PB8 | SCL |

## UART4

UART4 用于接收上位机发送的运动控制指令。

| 引脚 | 功能 |
|---|---|
| PC10 | UART4_TX |
| PC11 | UART4_RX |

## 定时器任务周期

| 定时器 | 周期 | 功能 |
|---|---:|---|
| TIM4 | 5 ms | 编码器读取、速度环控制、电机输出更新 |
| TIM4 | 10 ms | MPU6050 姿态更新、角度环控制 |
| TIM9 | PWM | 左右电机 PWM 输出 |

## 说明

- 本文档以当前代码中的引脚配置为准，实际接线时还需要结合电机驱动板和开发板原理图确认电源及地线。
- GPS、ESP8266、OneNet、DHT22 和循迹模块属于原始工程中的扩展模块，已移出当前 GitHub 展示版。
