# STM32F407 Patrol Car Control

基于 STM32F407 的园区巡航小车运动控制工程，围绕“上位机指令输入 - 传感器反馈 - 实时控制闭环 - 电机执行输出”构建完整控制链路。项目重点不是单个外设点亮，而是将编码器测速、MPU6050 姿态解算、PWM 电机驱动、UART 指令协议和定时中断调度整合为一个可实车运行的运动控制系统。

> 本仓库为个人项目整理版，保留运动控制核心代码。GPS、ESP8266、OneNet 等远程监测模块曾参与联调，当前仓库聚焦本人负责的底层运动控制、传感器反馈和控制算法实现，避免主题发散及敏感信息泄露。

## 项目亮点

- 构建小车运动控制主链路：上位机通过 UART4 下发速度、角度和运动时间，MCU 完成解析、调度、闭环控制和执行输出
- 设计 5ms / 10ms 双周期控制节拍：5ms 完成编码器测速与速度环控制，10ms 完成 MPU6050 姿态更新与角度环控制
- 实现速度环 + 角度环的串级控制：通过编码器速度反馈和姿态角反馈控制左右轮差速输出，支持目标速度和转向角度调节
- 完成 MPU6050 姿态反馈链路：包含零偏校准、加速度角度计算、陀螺仪积分、互补滤波和滑动平均处理
- 完成电机执行层封装：基于 TIM9 PWM 和方向控制 GPIO 输出左右轮控制量，并加入限幅保护提升运行稳定性
- 支持实车调试闭环：通过 OLED 显示目标速度、目标角度和左右轮速度，结合串口数据辅助定位控制状态和参数问题

## 控制流程

1. 上位机通过 UART4 发送运动指令，包含目标速度、目标角度和运动时间。
2. STM32F407 解析指令后更新控制目标，并进入定时器中断调度。
3. TIM8 / TIM5 读取左右轮编码器计数，计算实际轮速并作为速度环反馈。
4. MPU6050 采集加速度和角速度数据，经校准、滤波和姿态解算后输出姿态角。
5. 控制层根据目标速度、实际速度、目标角度和姿态反馈计算左右轮 PWM 输出。
6. OLED 实时显示关键运行数据，辅助现场调试和参数整定。

## 我的主要工作

- 负责运动控制核心流程设计，将编码器、MPU6050、PWM、电机方向控制、UART 指令解析和 OLED 调试显示串联为完整运行链路
- 编写左右轮速度反馈与差速控制逻辑，实现目标速度、转向角度到左右电机输出的转换
- 配置 TIM8 / TIM5 编码器接口，完成左右轮脉冲采集、速度换算和计数清零
- 基于 MPU6050 实现零偏校准、姿态角解算、互补滤波和滑动平均处理，为角度控制提供反馈量
- 设计速度环 PI 和角度环 PD 控制逻辑，加入输出限幅和运动时间控制，提升控制过程稳定性
- 使用 OLED、串口日志和实车运行结果进行联调，定位速度异常、转向不稳和参数不匹配等问题
