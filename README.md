# STM32F407 Patrol Car Control

基于 STM32F407 的园区巡航小车运动控制核心工程，主要用于验证 MCU 底层外设驱动、编码器测速、姿态解算、串级 PID 控制和整机调试能力。

> 本仓库为个人项目整理版，保留小车运动控制相关核心代码；GPS、ESP8266、OneNet 等远程监测模块已移入本地归档目录，避免仓库主题发散和敏感信息泄露。

## 功能特性

- 基于 TIM9 PWM 输出实现左右电机速度控制
- 基于 TIM8 / TIM5 编码器接口采集左右轮脉冲并计算速度反馈
- 基于 MPU6050 读取加速度和角速度数据，完成零偏校准、互补滤波和姿态角解算
- 基于速度环 + 角度环的串级控制结构，实现目标速度和转向角度控制
- 基于 UART4 接收上位机运动指令，支持速度、角度和运动时间参数解析
- 基于 OLED 显示目标速度、目标角度和左右轮速度，辅助现场调试
- 基于定时器中断实现 5ms 速度控制周期和 10ms 姿态更新周期

## 系统架构

```text
上位机指令
    │ UART4
    ▼
指令解析 / 目标速度 / 目标角度
    │
    ├── TIM4 定时中断
    │       ├── 10ms: MPU6050 姿态更新 + 角度环控制
    │       └── 5ms : 编码器测速 + 左右电机速度环控制
    │
    ├── TIM9 PWM 输出
    │
    └── OLED 状态显示
```

## 我的主要工作

- 完成小车运动控制主流程设计，配置电机驱动、PWM 输出、编码器测速、姿态反馈和 OLED 调试显示
- 编写左右电机驱动及差速控制逻辑，完成目标速度和转向角度到左右轮输出的转换
- 配置 TIM8 / TIM5 编码器接口，实现左右轮脉冲采集、计数清零和速度反馈
- 基于 MPU6050 完成陀螺仪零偏校准、加速度角度解算、陀螺仪积分和互补滤波
- 设计速度环 PI 与角度环 PD 控制逻辑，并通过限幅处理提升控制稳定性
- 使用 UART4 接收上位机控制指令，通过 OLED 和串口/实车测试辅助定位控制参数和运行状态

STM32F407 / C / 标准外设库 / TIM / PWM / UART / I2C / 编码器接口 / MPU6050 / OLED / 串级 PID / 互补滤波 / 电机控制

## 目录结构

```text
CORE/        Cortex-M4 内核及启动文件
FWLIB/       STM32F4 标准外设库
SYSTEM/      延时、串口、系统配置等基础模块
USER/        Keil 工程文件、main.c 和中断入口
HARDWARE/    电机、PWM、编码器、MPU6050、姿态解算、控制算法、OLED、UART4 等模块
docs/        项目说明和引脚连接文档
```

## 核心文件

```text
USER/main.c          主流程、TIM4 控制周期、中断调度
HARDWARE/control.c   速度环、角度环和差速控制
HARDWARE/encoder.c   编码器接口初始化与速度读取
HARDWARE/motor.c     电机方向与输出控制
HARDWARE/pwm.c       TIM9 PWM 初始化与占空比输出
HARDWARE/Angle.c     MPU6050 姿态解算与滤波
HARDWARE/uart4.c     上位机指令接收与解析
```
